# ГРЕННИ 13 — Побег от бабушки (Godot 4.7)

Перенос пародийной игры «ГРЕННИ 13» с самодельного C#-рендерера на **Godot 4.7**.
Полноценная 3D-игра от первого лица: четыре этажа, мебель, двери, Гренни, кошка
Маруся, капканы, пауки, бутылки, арбалет, три концовки и русский интерфейс.

## Запуск

```powershell
& 'C:\Users\saaho\Desktop\Godot.exe' --path .
```

Или откройте папку проекта в Godot 4.7 и нажмите **F5**.
Главная сцена — `scenes/main.tscn`.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` / стрелки | ходить |
| мышь | осматриваться |
| `R` | повернуться вправо (для игры без мыши) |
| `Shift` | бежать (шумно, тратит выносливость) |
| `Ctrl` / `C` | красться |
| `E` / ЛКМ | открыть дверь, обыскать шкаф, спрятаться, лезть на чердак |
| удержать `E` / ЛКМ | обыск, снятие замка, спуск через люк |
| `G` | бросить бутылку |
| `Q` | выстрел из арбалета |
| ПКМ | прицелиться |
| `F` | фонарик |
| `M` | миникарта |
| `Tab` | дневник |
| `Пробел` | вырваться из капкана |
| `Esc` | пауза |
| `F1` | отладочная панель |
| `F11` | полный экран |

## Что внутри

* **4 уровня:** дом, чердак, гараж, паучий подвал. Переходы — люки и лестницы.
* **Гренни:** патруль, слух, зрение, погоня, поиск, капканы, подъём на чердак,
  обход мебели по A*.
* **Маруся:** охраняет сундук с кодом; мяукает и зовёт Гренни. Молоко её успокаивает.
* **Три замка:** ключ, монтировка, записка с кодом 137. На «Сложно» и «Кошмаре» —
  четвёртый замок с кодом 274.
* **Концовки:** входная дверь, машина в гараже, секретная — мишка Тедди в колыбели.
* **Сложности:** Легко, Нормально, Сложно, Кошмар, Тренировка.
* **Ассеты:** оригинальные спрайты и текстуры из старой игры; остальные материалы,
  звук и иконки генерируются процедурно.

## Автотест

```powershell
& 'C:\Users\saaho\Desktop\Godot.exe' --path . -- --autotest
```

Тест проходит 57 проверок: построение мира, управление, физика дверей, укрытия,
капканы, шум, погоня, кошка, обыск, бутылка, арбалет, все уровни, машина,
три замка, дневник, поимка, победа, проигрыш, секретная концовка и панель F1.
Скриншоты сохраняются в `tests/shots/`.
