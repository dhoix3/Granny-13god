# ГРЕННИ 13 — Побег от бабушки (Godot 4.7)

Перенос пародийной игры «ГРЕННИ 13» с самодельного C#-рендерера на **Godot 4.7**.
Полноценная 3D-игра от первого лица: четыре этажа, мебель, двери, Гренни, кошка
Маруся, капканы, пауки, бутылки, арбалет, три концовки, сохранения, настройки
и русский интерфейс.

## Запуск

```powershell
& 'C:\Users\saaho\Desktop\Godot.exe' --path .
```

Или откройте папку проекта в Godot 4.7 и нажмите **F5**.
Главная сцена — `scenes/main.tscn`.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` / стрелки | ходить |
| мышь | осматриваться |
| `R` | повернуться вправо (для игры без мыши) |
| `Shift` | бежать (шумно, тратит выносливость) |
| `Ctrl` / `C` | красться |
| `E` / ЛКМ | открыть дверь, обыскать шкаф, спрятаться, лезть на чердак |
| удержать `E` / ЛКМ | обыск, снятие замка, спуск через люк |
| `G` | бросить бутылку |
| `Q` | выстрел из арбалета |
| ПКМ | прицелиться |
| `F` | фонарик |
| `M` | миникарта |
| `Tab` | дневник |
| `Пробел` | вырваться из капкана |
| `Esc` | пауза |
| `F1` | отладочная панель |
| `F11` | полный экран |

Меню (главное, пауза, настройки, сейвы, выбор сложности) работают и с клавиатуры,
и мышью: ховер подсвечивает пункт, клик выбирает.

## Что внутри

* **4 уровня:** дом, чердак, гараж, паучий подвал. Переходы — люки и лестницы.
* **Гренни:** патруль, слух, зрение, погоня, поиск, капканы, подъём на чердак,
  обход мебели по A*, анти-застревание. При патруле она тихо гудит — по звуку
  можно понять, где она (звук позиционный).
* **Маруся:** охраняет сундук с кодом; мяукает и зовёт Гренни. Молоко её успокаивает.
* **Три замка:** ключ, монтировка, записка с кодом 137. На «Сложно» и «Кошмаре» —
  четвёртый замок с кодом 274.
* **Концовки:** входная дверь, машина в гараже, секретная — мишка Тедди в колыбели.
* **Сложности:** Легко, Нормально, Сложно, Кошмар, Тренировка.
* **Сохранения:** автосейв при смене дня + 3 слота; экраны «СОХРАНИТЬ ИГРУ» /
  «ЗАГРУЗИТЬ ИГРУ», «ПРОДОЛЖИТЬ» в главном меню загружает свежий сейв.
* **Настройки:** громкость (общая / музыка / звуки), чувствительность мыши,
  инверсия Y, полный экран, тени фонарика, сглаживание. Хранятся между сессиями.
* **Звук:** все звуки синтезируются при запуске; шины Master/Music/SFX; музыкальная
  тема меню и эмбиент-петля в игре; мировые звуки — 3D-позиционные.
* **Ассеты:** оригинальные спрайты и текстуры из старой игры; остальные материалы,
  звук и иконки генерируются процедурно.

## Автотесты

Два уровня проверок:

**1. Логика карты без движка** (питон, проверяет достижимость всех предметов,
люков, укрытий и концовок, связность комнат):

```bash
python3 tests/logic_check.py
```

**2. Внутридвижковый прогон** (103 проверки: построение мира, управление,
физика дверей, укрытия, капканы, шум, погоня, кошка, обыск, бутылка, арбалет,
все уровни, машина, три замка, дневник, поимка, победа, проигрыш, секретная
концовка, панель F1, настройки, сохранение/загрузка, музыка, 3D-звук, мышь в меню):

```powershell
& 'C:\Users\saaho\Desktop\Godot.exe' --path . -- --autotest
```

Скриншоты сохраняются в `tests/shots/` (19 штук).

## Структура

```
assets/          оригинальные спрайты и текстуры
scenes/          main.tscn
scripts/         игровая логика на GDScript
docs/            память проекта (архитектура, решения, бэклог)
tests/           автотесты: autotest.gd (движок), logic_check.py (карта), shots/
addons/godot_ai/ MCP-плагин (не относится к игре)
project.godot    настройки проекта
```
