# ГРЕННИ 13 — Побег от бабушки (Godot 4.7)

Перенос пародийной игры «ГРЕННИ 13» с самодельного C#-рендерера на **Godot 4.7**.
Полноценная 3D-игра от первого лица: дом из четырёх уровней с интерьером и
атмосферой, Гренни, кошка Маруся, капканы, пауки, арбалет, три концовки,
сохранения, настройки и русский интерфейс. Один предмет в руках за раз —
планирование маршрута и рискованные возвраты — в духе оригинальной Granny.

## Запуск

```powershell
& 'C:\Users\saaho\Desktop\Godot.exe' --path .
```

Или откройте папку проекта в Godot 4.7 и нажмите **F5**.
Главная сцена — `scenes/main.tscn`.

### Android / сенсорный экран

На тач-устройствах автоматически появляется сенсорное управление: плавающий
виртуальный джойстик слева (до упора — бег), зона осмотра справа, кнопки
действий (E, бег, присед, фонарик, прицел, бутылка, выстрел, осмотр, дневник,
пауза). Мультитач: можно идти, осматриваться и действовать одновременно.
Размер элементов настраивается в Настройках. Меню и HUD адаптированы под
любые соотношения сторон.

## Что внутри

* **4 уровня:** дом, чердак, пристройка-гараж, паучий подвал. Планировка —
  единый источник `assets/house.json` (комнаты, мебель, лампы, люки);
  переходы — люки и лестницы по данным, у каждого свой шум и реплика.
* **Гренни:** патруль, слух, зрение, погоня, поиск, капканы, подъём на чердак,
  обход мебели по A*, анти-застревание. При патруле она тихо гудит — по звуку
  можно понять, где она (звук позиционный).
* **Маруся:** охраняет сундук с кодом; мяукает и зовёт Гренни. Молоко её успокаивает.
* **Один предмет в руках:** больше ничего не унести — брошенный предмет лежит
  в мире, пока его не поднимут. Обыск с занятыми руками предмет оставляет
  на месте. Маршрут планируй: ключ → куда положить → замок.
* **Три замка:** ключ, монтировка, записка с кодом 137. На «Сложно» и «Кошмаре» —
  четвёртый замок с кодом 274.
* **Концовки:** входная дверь, машина в гараже, секретная — мишка Тедди в колыбели.
* **Сложности:** Легко, Нормально, Сложно, Кошмар, Тренировка.
* **Сохранения:** автосейв при смене дня + 3 слота; экраны «СОХРАНИТЬ ИГРУ» /
  «ЗАГРУЗИТЬ ИГРУ», «ПРОДОЛЖИТЬ» в главном меню загружает свежий сейв.
* **Графика:** запечённая вершинная AO (контактные тени без GPU-цены),
  normal-карты, профили качества (Низкий/Средний/Высокий), пылинки в свете,
  парящий перед камерой предмет вместо рук (появление, покачивание,
  осмотр на `X`), камин/ванная/колыбель/машина, «выгоревшие» лампы,
  плавное приседание и крен камеры.
* **Настройки:** громкость (общая / музыка / звуки), чувствительность взгляда,
  профили качества графики, инверсия Y, полный экран, тени фонарика,
  сглаживание, масштаб тач-элементов. Хранятся между сессиями.
* **Звук:** 57 сгенерированных WAV 32 кГц; шины Master/Music/SFX; шаги по
  поверхностям (дерево/ковёр/кафель/бетон) — у Гренни свои по этажам;
  амбиентные петли этажей (ветер/чердак/подвал) с кроссфейдом и случайными
  событиями (скрипы, падения, царапанье окон, гром); мьюфинг звука через
  стены (окклюзия); музыкальные состояния — меню / эмбиент / напряжение /
  погоня / возврат; мировые звуки — 3D-позиционные.
* **Ассеты:** оригинальные спрайты (Гренни, Маруся, иконки) из старой игры;
  текстуры, звук и шрифты генерируются офлайн-скриптом `tools/gen_assets.py`
  (детерминированно, воспроизводимо).

## Автотесты

Два уровня проверок:

**1. Логика карты без движка** (питон, проверяет достижимость всех предметов,
люков, укрытий и концовок, связность комнат):

```bash
python3 tests/logic_check.py
```

**2. Внутридвижковый прогон** (218 проверок: построение мира из house.json,
управление, физика дверей, укрытия, капканы, шум, погоня, кошка и молоко,
обыск и лимит «один предмет», дроп/подъём с пола, люки по данным, арбалет и
стрелы, машина, три замка, дневник, поимка с дропом, победа, проигрыш,
секретная концовка, панель F1, настройки и их проводка, сохранение/загрузка/
миграция v1→v2/повреждённые сейвы, музыкальные состояния, амбиент-слои и
окклюзия, парящий предмет, мышь в меню, профили качества, сенсорная
проводка; итог печатает сам тест в строке `checks=…`):

```powershell
# первый раз — импорт ресурсов (создаёт кэш .godot/, нужен один раз)
& 'C:\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --import --path .

# затем автотест; тест сам закрывает процесс, exit code 0 = успех, 1 = провалы
& 'C:\Godot\Godot_v4.7.2-stable_win64_console.exe' --path . -- --autotest
$LASTEXITCODE
```

Ожидаемый результат (проверено реальной сборкой Godot 4.7.2 в headless):
`AUTOTEST checks=218 fails=0`, код возврата 0, плюс `LOGIC CHECK: checks=439
fails=0` у питон-проверки. Тест печатает замер CPU-времени кадра
(`AUTOTEST perf frame_ms avg=… p95=…`): 6.89 / 7.57 мс — на уровне PR #2
(6.89 / 7.58), без деградации. В dev-сборках Godot после
этого в консоли может появиться Jolt-assertion и предупреждение об утечке
инстансов ObjectDB — это шум teardown самой dev-сборки движка после
финального `print`, на результат не влияет (в release-сборках отсутствует).
В headless-режиме все 218 проверок работают; скриншоты в этом режиме
недоступны и пропускаются.
Скриншоты при обычном запуске сохраняются в `tests/shots/`.
Подробная инструкция для Windows 11: `docs/TESTING_WINDOWS.md`.

## Структура

```
assets/          спрайты, текстуры, звук; house.json — планировка дома
tools/           gen_assets.py (текстуры/звук), gen_house.py (планировка)
scenes/          main.tscn
scripts/         игровая логика на GDScript
docs/            память проекта (архитектура, решения, бэклог)
tests/           автотесты: autotest.gd (движок), logic_check.py (карта)
addons/godot_ai/ MCP-плагин (не относится к игре)
project.godot    настройки проекта
```
