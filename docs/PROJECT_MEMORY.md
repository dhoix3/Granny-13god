## 1. АРХИТЕКТУРА ПРОЕКТА

Godot 4.7 (Forward Plus, физика Jolt). Главная сцена `scenes/main.tscn` —
единственная, содержит один Node3D со скриптом `scripts/game.gd`. Вся игра
строится кодом (процедурно), сцен в редакторе почти нет. Весь UI рисуется
вручную в `_draw()` (`scripts/ui.gd`). Весь звук синтезируется при запуске
(`scripts/audio.gd`), внешних аудиофайлов нет.

```
game.gd (GrannyGame, Node3D)        — контроллер: состояния, взаимодействия, замки, шумы, endings
├── world_builder.gd (WorldBuilder) — мешы уровня (SurfaceTool-батчи), двери, мебель, лампы, капканы, пауки
│   └── world_gen.gd (WorldGen)     — чистая генерация раскладки 4 уровней + распределение предметов
│       └── level_data.gd (LevelData) — тайлы, двери, контейнеры, укрытия, A*, LOS, ai_blocked
├── player.gd (PlayerBody, CharacterBody3D) — движение, стамина, батарейка, укрытия, вьюмодель руки
├── granny.gd (GrannyAI, Node3D)    — FSM: PATROL/INVESTIGATE/CHASE/SEARCH/CLIMB/STAGGER, A*, анти-застревание
├── cat.gd (CatAI, Node3D)          — Маруся: злость на шум/свет/сундук, молоко, мурчание
├── bottle.gd (ThrownBottle)        — баллистика бутылки, разбитие, срабатывание капканов
├── trap_node.gd (TrapNode)         — визуал капкана (челюсти)
├── ui.gd (GameUI, Control)         — весь интерфейс (_draw), миникарта, дневник, экраны
├── audio.gd (autoload "Audio")     — процедурные WAV, пул плееров, музыка/шины
├── items.gd (Items)                — ID, названия, подсказки, иконки (атлас + процедурные)
├── materials.gd (Mats)             — все материалы и процедурные текстуры
├── settings.gd (GameSettings)      — настройки: громкости, мышь, видео; user://settings.cfg
└── save_system.gd (SaveSystem)     — сохранения: user://saves/{auto,slot1..3}.json
```

Состояния игры (game.gd): TITLE, DIFF, INTRO, PLAY, PAUSE, CAUGHT, WIN, OVER,
HELP, SETTINGS, SAVE, LOAD.

Константы тайлов/предметов совпадают со старой C#-версией — не менять значения.

## 2. РЕАЛИЗОВАННЫЕ СИСТЕМЫ (проверено)

* 4 уровня: дом 32×32, чердак 24×24, гараж 16×16, подвал 20×20. Люки-переходы.
* Игрок: WASD, бег/крдение, стамина, фонарик с батарейкой, капканы, укрытия
  (2 шкафа + под кроватью), арбалет (транквилизатор → STAGGER), бутылки-отвлекалки.
* Гренни: патруль по точкам, слух (radius×hear_mul, громкие шумы сквозь этажи),
  зрение (дистанция×FOV×LOS, множители на фонарик/крдение), погоня с repath 0.45с,
  поиск после потери 3.5с, проверка укрытий (hide_check на сложность), подъём на
  чердак (CLIMB), стан от стрелы, расстановка капканов, анти-застревание
  (watchdog + teleport_to_walkable + обход по 9 направлениям).
* Маруся: злится на бег/свет/близость/обыск сундука → мяу → Гренни узнаёт
  (attic_alert_t ускоряет переход Гренни на чердак). Молоко усмиряет.
* Предметы: ключ, монтировка, записка 137 (сундук чердака), молоко, батарейка,
  бинт, бутылки, арбалет+3 стрелы, ключ и аккумулятор машины (гараж — фиксированы),
  записка 274 (4-й замок, СЛОЖНО/КОШМАР), фото (+1 день, подвал), Тедди (подвал).
* Три замка входной двери + 4-й на высоких сложностях. Три концовки: дверь,
  машина, секретная (Тедди в колыбель при 3 замках + собранной машине).
* Сложности: ЛЕГКО/НОРМАЛЬНО/СЛОЖНО/КОШМАР/ТРЕНИРОВКА (god_mode).
* UI: меню, выбор сложности со шкалами, КАК ИГРАТЬ, интро, HUD (замки, день,
  миникарта, полосы, инвентарь-иконки, подсказки, прогресс-бары), дневник,
  пауза, экраны поимки/победы/проигрыша, F1-отладка, F11-фуллскрин.
* Аудио: ~30 процедурных WAV-звуков; 3 шины (Master/Music/SFX); музыкальные
  петли (меню-тема, эмбиент дома); 3D-позиционирование мировых звуков
  (шаги/двери/крик Гренни, мурлыканье/мяу Маруси, гул Гренни, бутылки,
  капканы, пауки, машина); гул Гренни при патруле как индикатор позиции.
* Настройки: громкость (общая/музыка/звуки), чувствительность мыши, инверсия Y,
  полный экран, тени фонарика, MSAA; хранение в user://settings.cfg.
* Сохранения: автосейв при смене дня + 3 слота; экраны СОХРАНИТЬ/ЗАГРУЗИТЬ
  (мета: сложность, день, замки, время, дата); «ПРОДОЛЖИТЬ» грузит свежий сейв.
* Мышь в меню: ховер + клики во всех экранах.

## 3. ПРОВЕРКИ (как проверять)

1. Статика GDScript: `gdparse` (gdtoolkit 4.x) по всем *.gd — 0 ошибок.
2. Логика карты без движка: `python3 tests/logic_check.py` — 88 проверок:
   достижимость всех предметов/люков/укрытий/концовок, связность комнат,
   валидность спавнов. 88/88 OK (см. раздел 7).
3. В движке: `Godot --path . -- --autotest` — 118 проверок. Счётчик

   раз; фактическое число печатает сам тест (`checks=…`, `AUTOTEST OK/FAILED`)
   `tests/shots/`. Выходной код 0 при успехе.
4. Ручной прогон сценариев: см. README «Управление».

## 4. ТЕКУЩИЕ ПРОБЛЕМЫ / ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

* Godot-движок в CI-песочнице недоступен (ресурсы release-assets.githubusercontent
  заблокированы) — внутридвижковые проверки запускаются локально у пользователя.
* Гренни не спускается в гараж/подвал (только дом↔чердак) — сознательное
  решение в духе оригинала: подвал и гараж «безопасные» зоны. Если менять —
  аккуратно балансировать cat_range и слепые зоны.
* Пауки статичны (декор + урон в радиусе) — по мотивам оригинала.
* Ввод только клавиатура+мышь; геймпад не поддерживается.
* Вьюмодель — простые примитивы; Гренни/Маруся — спрайты-биллборды.

## 5. ПРИНЯТЫЕ РЕШЕНИЯ

* Не переписывать работающие системы; расширять инкрементально.
* Весь новый UI рисуется в ui.gd тем же стилем (никаких Control-сцен).
* Звук: новые мировые звуки — через Audio.play3d(...) с шиной SFX; музыка —
  шина Music; плеер 3D создаётся на время и освобождается сам.
* Сохранение: JSON в user://saves; мир не пересобирается — применяется
  состояние поверх детерминированного (seed фиксирован 20261119);
  обысканные контейнеры обнуляются, чтобы предметы не дублировались.
* Настройки — ConfigFile user://settings.cfg, применяются при старте и на месте.
* Мышь в меню: ui.gd строит прямоугольники пунктов, game.gd делает hit-test.

## 8. АУДИТ PR #1 (вторая сессия, до слияния)

Полный технический аудит собственных изменений. Найдено и исправлено 8 проблем:

1. **Ховер-прямоугольники паузы не строились** (`ui.gd::_draw_pause`) — после
   перехода TITLE→PAUSE `_update_menu_hover` использовал прямоугольники меню
   заголовка: наведение в паузе двигало выбор по чужим координатам. Исправлено:
   пауза строит свои rect-ы, добавлена подсветка ховера.
2. **Клик мышью в паузе не работал** (`game.gd::_menu_click`) — ветка
   STATE_PAUSE отсутствовала. Добавлена: клик по подсвеченному пункту активирует.
3. **F11-синхронизация была недетерминированной** — `settings.fullscreen`
   читался из `win.mode` ПОСЛЕ присваивания (в headless режим может не
   примениться). Исправлено: целевой режим вычисляется до присваивания.
4. **Музыка стартовала без fade-in** из тишины (`audio.gd::set_music`) —
   `music_fade` был 1.0. Исправлено: при старте из тишины fade с нуля.
5. **Загрузка сейва не защищала позицию игрока** — мусорные координаты из
   повреждённого файла могли поместить игрока вне карты (падение в пустоту).
   Добавлены клампы в границы уровня + fallback на спавн уровня, если точка
   в стене; то же для Гренни (кламп + её собственная релокация).
6. **Капканы из сейва без проверки** — кламп координат, кламп индекса уровня,
   добавление только на FLOOR/RUG.
7. **Инвентарь из сейва без фильтра** — отфильтрованы NONE и несуществующие ID
   (через `Items.display_name(id) != ""`); клампы deaths/play_time.
8. **Скриншот 19_saves снимался в состоянии PAUSE** (после записи) — перенесён
   на момент, когда экран сейвов реально виден.

Также в UI добавлены сбросы hover/diff-rect-ов на экранах, где они не
используются (гигиена ховера), и слайдер настроек сдвинут — текст значения
не вылезал за панель.

### Новые тесты в autotest (пункт 10 задания)

* Проводка настроек: invert_y → invert_look, sensitivity → look_scale.
